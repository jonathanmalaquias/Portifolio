# 📱 QR Code Generator with GUI

A simple and efficient desktop application to generate QR Codes with custom filenames and a Dark/Light mode toggle.

## 🚀 Features
* **User-Friendly Interface**: Built with Flet (Flutter for Python).
* **Customization**: Choose the link and the output filename.
* **Theme Toggle**: Support for both Dark and Light modes.
* **Portable**: Available as a standalone `.exe` for Windows.

## 🛠️ Tech Stack
* **Python 3.12+**
* **Flet**: For the Graphical User Interface (GUI).
* **QRCode**: For the generation logic.
* **Pillow**: For image processing.
